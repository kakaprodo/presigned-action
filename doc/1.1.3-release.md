# Release 1.1.3

## Highlights

- Add `reference_text` to temporary access keys, populated from the generated custom-data dataKey.
- Reuse unexpired access keys by matching independence, accessible ID, expiry, and `reference_text`.
- Make the initial temporary-access-key migration the canonical schema for independent keys.
- Make follow-up temporary-access-key migrations safe when columns already exist or have already been removed.
