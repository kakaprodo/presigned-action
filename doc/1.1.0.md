# Release 1.1.0

## Highlights

- Added the `ActionValidator` class to handle grouped and standalone action validation. this is like laravel Gate for presigned-action:

You register first a validator(it can be in the `register` method of any service provider):

```php
PresignedAction::validator()->register('orders', [
    'owns' => fn (TemporaryAccessKey $accessKey, $orderId) => true,
]);
```

The you call it wherever you want:

```php
$hasPassed = PresignedAction::validator()->check('orders.owns', [$orderId]);
```

- Added `TemporaryAccessKey::can(array $permissions)` as a shortcut for
  `hasPermission()`.
- Added `PresignedActionOriginMiddleware` and
  `PresignedActionPermissionMiddleware`.
- Added the `presigned-action:purge-expired` Artisan command.
- Validator failures throw `PresignedActionException`; custom error messages
  are supported.
