# Release 1.2.1

## Highlights

- Add a fetch API endpoint for pulling temporary authentication-code details by `state_key` and UUID.
- Apply the configurable rate limit to both generation and fetch requests.
- Support optional generation metadata and merge it with subscriber metadata during association.
- Validate `state_key` as a required string with a maximum length of 500 characters.

## Example

```php
$code = PresignedAction::generateTempAuthCode([
    'state_key' => $stateKey,
    'metadata' => ['device_key' => 'key-here'],
]);

PresignedAction::associateTempAuthCode([
    'uuid' => $code->uuid,
    'subscriber_type' => 'subscriber',
    'metadata' => ['access_token' => $token],
]);

$result = PresignedAction::fetchTempAuthCode($stateKey, $code->uuid);
```

The API to fetch a temp auth code is also available at:

```text
GET /api/presigned-action/temp-auth-codes/{state_key}/{uuid}
```
